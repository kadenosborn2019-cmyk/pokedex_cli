This is a command line interface designed to use the Poke_API and provide an experience
like the game series. Use command "help" for a list of available commands. The usage descriptor of the help
command provides a live update to the list of available commands and there usage.

to build the cli you will need to install go on your enviorment
then use "go install github.com/kadenosborn2019-cmyk/pokedex_cli@latest"
